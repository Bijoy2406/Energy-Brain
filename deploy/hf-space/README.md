# Gridpilot AI

Plan a commercial site's solar, battery, flexible loads and backup generator.
Compare electricity cost and CO2, inspect the schedule, and ask why the optimiser made a decision.

Synthetic load, simulated PV, synthetic outages. Historical replay.
Weather comes from NASA POWER and Open-Meteo; this is a demonstration, not a live site controller.

The dashboard and API share this Space. API documentation: `/docs`; service status: `/health`.
